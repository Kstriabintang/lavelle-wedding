# Lavelle

**Lavelle** is an elegant digital wedding invitation service. We craft refined, personal, and timeless online invitations that let couples share their special day with every guest through a single link — beautifully designed and effortless to send.

## Features

- **RSVP** — guests confirm their attendance directly from the invitation.
- **Photo Gallery** — showcase pre-wedding photos and cherished moments.
- **Love Story** — a graceful timeline of the couple's journey.
- **Countdown Timer** — a live count down to the big day.
- **Google Maps Location** — venue map with one-tap directions.
- **Digital Envelope** — receive gifts of love via bank transfer or QRIS.
- **Background Music** — a tasteful soundtrack that sets the mood.
- **Custom Design** — themes, colors, and layouts tailored to each couple.

## Tech Stack

- **HTML**
- **CSS**
- **JavaScript**

Built as a fast, fully static site — no backend or database required.
